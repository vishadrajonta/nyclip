# NYClip

A first-draft games site about everyday life in New York City, made to look like the 2001 MiniClip homepage: a small fixed-width page, cropped thumbnails, short funny blurbs, and a list of all the games.

Two games are playable in the browser: **Everything Bagel** and **Rooftop Run**. The rest have a page and a blurb, and say they are still in the shop.

This is a school project (The New School). It is a complete first draft, not a finished site.

Open `index.html`, or if you are looking at the GitHub Pages URL, start there.

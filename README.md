# NYC.exe

A first-draft games site about everyday life in New York City. Early-2000s web page, subway signs, a skyline, short funny blurbs. Blue, white, and orange.

Playable in the browser: **Logo Builder**, **Midtown Drive**, **Everything Bagel**, and **Rooftop Run**. The rest are still in the shop.

There is also a guestbook and, on the first visit, a fake dial-up intro.

This is a school project (The New School). It is a complete first draft, not a finished site.

Live: https://vishadrajonta.github.io/nyclip/

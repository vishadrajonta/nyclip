# NYClip

A first-draft games site about everyday life in New York City. Early-2000s web page, subway signs, a bodega awning, short funny blurbs.

Two games are playable in the browser: **Everything Bagel** and **Rooftop Run**. The rest are still in the shop.

This is a school project (The New School). It is a complete first draft, not a finished site.
